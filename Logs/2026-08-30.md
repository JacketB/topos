# Отчет о разработке Topos GIS — 2026-08-30

## 1. Прямая перезапись открытого проекта при сохранении
- В `ProjectManagerService` разделены методы `saveProject(scenarioData)` и `saveProjectAs(scenarioData, name)`:
  - При открытии существующего файла (`.tps` / `.json`) с диска через нативный диалог или список недавних проектов сохраняется его абсолютный путь `filePath`.
  - При нажатии «Сохранить» (тулбар, горячая клавиша `Shift+S`, модальное окно проектов) проверяется наличие `filePath`: если путь существует, файл напрямую перезаписывается без повторного открытия диалогового окна выбора папки.
  - Если проект новый и еще не был сохранен на диск, автоматически вызывается нативный диалог выбора папки и имени файла (`rfd::FileDialog` / `choose_save_path`).
  - Пункт «Сохранить как...» в окне управления проектом (`ProjectModalComponent`) всегда вызывает диалоговое окно для сохранения копии проекта по новому пути.
- В `ProjectsView` и `ProjectModalComponent` при клике на проект из списка недавних файлов актуальные данные автоматически считываются с диска по сохраненному `filePath`.

## 2. Название проекта и индикатор статуса сохранения в статус-баре
- В левую часть нижнего статус-бара (`status-left`) добавлен интерактивный бейдж с именем текущего проекта (`.status-project-btn`):
  - При наведении отображается всплывающая подсказка с полным путем к файлу проекта или пометкой `(Новый проект, не сохранен на диск)`.
  - Клик по названию проекта открывает окно управления проектами (`ProjectModalComponent`).
- Внедрен реактивный индикатор статуса сохранения (`saveStatus`):
  - Во время процесса сохранения: спиннер и статус `Сохранение...`.
  - При успешной перезаписи или сохранении: зеленая иконка и статус `Проект сохранен` / `Файл скачан` (с автоскрытием через 3.5 с).
  - При ошибке ввода-вывода: красная иконка и статус `Ошибка сохранения`.
  - В обычном режиме: лаконичный индикатор готовности системы `Готов` / `Загрузка...`.

## 4. План расширения векторной карты приграничными районами (15–20 км)
- Сформирован расчет охвата геоданных BBOX `[22.70, 50.95, 33.20, 56.45]` (Польша, Литва, Латвия, Россия, Украина).
- Определен стек генерации: компилятор Planetiler (Java 21) с генерацией PMTiles $Z0..Z14$ по схеме OpenMapTiles с кириллическими подписями `name:ru`.
- Оценен объем дискового пространства: итоговый файл `belarus.pmtiles` $\approx 620\dots720\text{ МБ}$, временные ресурсы при компиляции $\approx 5\dots7\text{ ГБ}$.
